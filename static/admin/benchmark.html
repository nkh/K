vrunner Browser Rendering Time Benchmark

This benchmark measures actual rendering time in the browser — including DOM manipulation, layout recalculation, style resolution, paint, and composite. Each iteration forces a synchronous layout+paint via void el.offsetHeight and uses requestAnimationFrame to measure real frame times. Two approaches are compared:

A) innerHTML full replacement — the current approach where the entire <pre> content is replaced with new HTML, destroying all existing DOM nodes and creating new ones from scratch.
B) Incremental DOM patching (Level 3) — only changed <span> elements are updated in-place using setAttribute('style', ...) and textContent, exactly matching the vrunner Level 3 implementation. No DOM nodes are created or destroyed.
